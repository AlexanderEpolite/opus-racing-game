# Racing Game made by Claude Opus 5

**No part of this repository was human made**, except the prompt below.  This is a benchmark to determine Claude Opus 5's capabilities.

# Play the Game

https://co5-game.epolite.net/

# Prompt #1 - 1 hour 6 minutes (July 24 2026)

Make a racing game in this repository, in HTML.  It will use any library you want.  Requirements:
- Must be 3d
- Must include items
- Must include speed boosts
- Controls must be intuitive
- Must have ramps and gliders
- Must have laps and basic NPC/CPU characters (their logic doesn't have to be good)

This repo is currently empty.  Use any frontend framework (or lack thereof) you wish.

# Prompt #2 - 1 hour 12 minutes (July 24 2026)
Make multiplayer support, and make it so that you can't glide off course onto another part of the track, people were using it to skip.

Make a single .ts for the server, and make the server connect to wss://co5-game-ws.epolite.net/

Also make three new tracks, one ice themed, and another forest themed, and one you pick. all should take about 3 minutes to complete (about 2x as long as the current one).  When starting a game lobby with a code, the room organizer will choose the track.

Assume all clients are honest, no anti-cheat needed.  For track 3 that you choose the theme, make it so that it is one continuous track, and not a loop.
